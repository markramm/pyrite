- **`pyrite task create` now accepts `--field key=value` (#397).** A KB whose `task` type declares required fields — the desk schema's `project`/`kind` — could not be used with `task create` at all: validation refused the create, and there was no option to supply the fields. `--field` (repeatable, no short flag — `-f` is already `--format` on the task commands) fills them, and is refused for any key that already has its own option, for `status`, and for a task's managed audit-trail fields.
