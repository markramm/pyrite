- **Ephemeral KBs stay private across restarts.** A user's ephemeral KB is private (`default_role: none`: its creator and global admins only), and that policy is now written to the KB registry and `config.yaml` in the same step that creates the KB, so every process — a restarted server, a second worker, the CLI — applies it. Ephemeral KBs created by an admin or `pyrite kb create --ephemeral` are private by default too. The creator's grant and the KB are created together: if the grant cannot be recorded, the KB is removed. **Operator note:** ephemeral KBs created by earlier versions were readable (and writable, at write tier) by every signed-in user after any restart. On load, an ephemeral KB with no `default_role` is now treated as private and a warning names it.
