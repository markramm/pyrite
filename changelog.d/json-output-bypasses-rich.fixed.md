- **`--json` output is valid JSON again when piped or run under `FORCE_COLOR` (#321).** Nineteen `--json` code paths printed through `console.print(json.dumps(...))`, which hands the payload to Rich as rich text: with stdout on a pipe Rich cannot measure a terminal, falls back to 80 columns and hard-wraps, inserting real newlines inside string values, and under `FORCE_COLOR` it additionally syntax-highlights the output with ANSI escapes. Either one made `json.loads` fail for the caller that asked for machine-readable output — a title, body excerpt or source URL over ~70 characters was enough. All nineteen sites now go through a new `pyrite.utils.json_utils.echo_json`, which writes to stdout with the builtin `print` and never touches Rich.
