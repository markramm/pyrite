- The web client's live-update socket now follows the signed-in user. Logging in, logging out (the sidebar's "Log out" now clears the client's session state) or switching user closes the old socket and opens exactly one new one. A signed-out tab no longer receives, or toasts, events from the previous user's KBs. A handshake the server refuses now shows "Real-time updates unavailable" and is not retried until the user changes; a dropped connection keeps its backoff. (#336)
