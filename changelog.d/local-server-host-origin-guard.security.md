- **An auth-disabled server answers only the hostnames it expects and refuses cross-origin writes.** With `auth.enabled` false, requests must be addressed to `localhost`, `127.0.0.1`, `[::1]`, the non-wildcard bind host, or a name in the new `allowed_hosts` setting (`PYRITE_ALLOWED_HOSTS`); any other `Host` gets 421. `POST`/`PUT`/`PATCH`/`DELETE` requests whose `Origin` (or, without one, `Referer`) is neither the server's own origin nor listed in `cors_origins` get 403. Both rules cover the whole app, including `/mcp` and `/ws`; clients that send neither header (CLI, `curl`, agents) are unaffected. **Operators:** if you serve an auth-disabled instance under a LAN or proxy hostname, add it to `allowed_hosts`; if the web UI runs from another origin (for example a Vite dev server on a non-default port), add that origin to `cors_origins`. See docs/configuration.md.
