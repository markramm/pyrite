- `scripts/verify-red.sh` and the CI `verify-red` job now share one owner for reverting and restoring the implementation files: the files are written directly and put back byte for byte after a verdict, a refusal, a killed or timed-out test run, SIGINT, SIGTERM, SIGHUP or SIGQUIT; the git index is never touched; an edit made during the run is never overwritten; and a file that cannot be restored is named, with a non-zero exit. After a SIGKILL the next run names the files still reverted instead of asking you to commit them. Checkout conversion (`eol=crlf`) and non-UTF-8 files restore correctly, and directories the revert created are removed. `unittest.mock` patch misses and `monkeypatch.delattr` count as weak reds, text quoted in an assertion message no longer does, and `verify-red.sh` reports a killed, interrupted or internally failing run, or a node id pytest cannot find, as "no claim" instead of "fails without the fix" (#368).
