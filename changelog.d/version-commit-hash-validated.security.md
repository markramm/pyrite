- `GET /api/entries/{id}/versions/{commit_hash}` now accepts only a hex git object id (4 to 64 characters, abbreviated or full) and refuses anything else with `400 INVALID_REF` before git runs. Previously the value reached `git show` unchecked, so a read-tier caller could influence how git ran. `git show` now also ends option parsing before the object name. Symbolic refs such as `HEAD` or a branch name are no longer accepted on this route. No operator action is needed (#333).
